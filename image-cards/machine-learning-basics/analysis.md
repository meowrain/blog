## Value Proposition

**为什么用户要看？**
1. **系统学习**: 从样本、特征到模型拟合，一条龙讲清ML核心概念
2. **直观理解**: 用电影分类的KNN例子让抽象概念变得具体
3. **知识框架**: 建立完整的机器学习知识体系地图

**收藏理由**: ML入门知识体系完整，适合反复查阅复习
