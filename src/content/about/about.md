你好，我是 **MeowRain**，一名后端开发。

白天写业务代码，晚上折腾自己的小站。这个博客从 2021 年开始断断续续地写，最早只是把学习笔记搬上来，后来慢慢变成了一个放文章、碎碎念和项目的地方。

## 我在写什么

- **Java / JVM**：并发、集合、反射与泛型，以及面试里绕不开的那些底层细节
- **Go**：语言特性、运行时和工程实践
- **操作系统与网络**：IO 模型、TCP/IP、进程线程这些基础
- **开发日记**：踩坑记录、工具配置、线上问题的排查过程

大部分文章是自己学习时整理的，所以会有不严谨的地方，发现错误欢迎在文章底部联系我，或者直接在 GitHub 上提 issue。

## 这个站点

基于 [Fuwari](https://github.com/saicaca/fuwari) 二次开发，用 Astro 生成静态页面，内容都是仓库里的 Markdown 文件。源码在 [GitHub](https://github.com/meowrain/blog)，想复刻的话可以先看 `src/config.ts` 和 `astro.config.mjs`。

站点上还有一些自己加的东西：

- **系列**：把同一主题的文章串成章节，可以顺着上一章往下读
- **碎碎念**：短笔记时间线，放不适合单独成篇的想法
- **AI 助手**：右下角的胶囊，可以在站内找文章，也能讲解当前这篇
- **年度报告**：按年统计写了多少、什么时候写
